💎 DevVault — Your Developer Knowledge Hub

DevVault is a personal developer knowledge hub designed to help students and programmers organize coding notes, save useful programming resources, store code snippets, and document debugging solutions in one place.

🚀 About the Project

Learning to code involves exploring programming languages, solving errors, and collecting useful resources. DevVault provides a simple and organized space to manage this knowledge and make it easy to find whenever needed.

✨ Features

- 📝 Coding Notes — Create and organize programming notes.
- 🔗 Resource Library — Save useful coding websites, tutorials, and documentation.
- ⌨️ Code Snippets — Store frequently used code examples and commands.
- 🐛 Bug Journal — Record programming errors and their solutions.
- 🔍 Search Functionality — Quickly find saved notes and resources.
- 🌙 Dark Mode — Switch between light and dark themes.
- 💾 Local Storage — Save information in your browser.
- 📱 Responsive Design — Use the dashboard on desktop and mobile screens.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

🎯 Project Objectives

⚙️ How to Use

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Start organizing your coding notes, resources, snippets, and debugging solutions.
